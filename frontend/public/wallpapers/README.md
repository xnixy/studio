# Studio wallpapers

Clean **brand-only** soft gradients (no multi-color bokeh). Used under Soft / Frosted glass.

| Pattern | Example |
|---------|---------|
| `{brand}-dark.jpg` | `gold-dark.jpg` (gold glow on dark) |
| `{brand}-light.jpg` | `indigo-light.jpg` |
| `black-dark.jpg` | Pure black + soft violet glow |

Rebuild:

```bash
python frontend/scripts/build_wallpapers.py
```
